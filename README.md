# 田间时刻 · QQ 农场收菜时间计算器

一个在本地运行的网页，提供单次收菜时间计算和全天最优种植规划。时间输入和结果都按北京时间（UTC+08:00）解释和显示，精确到分钟。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。代码检查、计算测试和生产构建：

```bash
npm run lint
npm test
npm run build
```

## 计算规则

- 生长档位：4、8、12、24 小时。
- 第一季：播种时间 + 生长时间 × 土地系数。
- 第二季：第一次收菜时间 + 生长时间 ÷ 2 × 同一土地系数。
- 普通、黑、金土地的系数分别为 1、0.9、0.8；土地只需选择一次，两季保持一致。
- 第一次实际收菜时间留空时，第二季按第一季成熟时立即收菜估算；填写后按实际时间重新计算。实际时间不得早于第一季成熟时间。

## 全天规划

- 选择计划日期、一块土地、可用种子品类和多个可操作时段。种子数量不限；每个时段限同一天，起点早于终点，重叠时段自动合并。播种、收菜和换种只能在这些时段内进行，均按同一分钟完成。
- 可用种子分为普通一季、普通两季、活动一季、活动两季。活动一季预设 12 小时、经验权重 24；两个活动分组都可从分组标题旁添加自定义种子，添加后立即参与规划。自定义种子只保留在当前页面会话中。
- 从空地开始规划。今天从点击“生成最优方案”时的下一分钟起算，其他日期按完整一天计算；成熟时不在线则等到下一个可操作时刻收菜。
- 两季种子的第二季从第一次计划收菜时间起算，收完第二季才能换种。只有当天能完成全部季数的作物才纳入方案。
- 经验权重始终最高优先。若多个方案达到相同的最高权重，可选择“次数较少”“中等次数”或“次数较多”，默认“次数较多”。中等次数按最少与最多收菜次数的中点选择，等距时优先选择更早完成的方案。普通种子第一季权重为标称生长小时数，第二季为其一半；活动种子使用配置中的权重；土地只影响成熟时间。
- 种子品类、经验权重和土地增益统一定义在 `src/config.ts`，两个视图共用。

页面使用 Vue 3、Vite、TypeScript 和 Naive UI。计算在浏览器内完成，输入不会上传或持久保存。选择“此刻”时按当前分钟记录播种时间。

日期选择器的面板使用设备本地时区。在实行夏令时的地区，切换当天个别本地不存在的时间可能无法在面板中选取；已选时间的收获计算始终按北京时间解释。

## GitHub Pages 部署

网站地址：<https://longshihui.github.io/qq-farmer/>。

仓库的 **Settings → Pages → Build and deployment → Source** 设为 **GitHub Actions**。推送到 `main` 后，工作流会运行测试、以 `/qq-farmer/` 为资源基路径构建，并部署 `dist`。也可以在 **Actions → Deploy GitHub Pages → Run workflow** 手动部署。
